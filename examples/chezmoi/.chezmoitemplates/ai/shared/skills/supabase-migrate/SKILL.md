# supabase-migrate

Locate the project’s migration directory and database conventions. Review SQL, RLS policies, UUID and timestamp defaults, data preservation and rollback. Validate in an isolated database when available. Migration generation is separate from permission to apply it to production.

This public example is independent of private skill content. Legacy conversion preserves the existing reviewed skill verbatim.
