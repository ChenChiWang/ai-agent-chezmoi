# deploy

Identify the actual deployment files and services first. For Docker Compose, Supabase, Kong, Nginx or Vite projects, use the repository’s configuration and pinned versions. Review restart and downtime impact; deployment examples are not authorization to stop services. Keep environment values out of logs.

This public example is independent of private skill content. Legacy conversion preserves the existing reviewed skill verbatim.
