# excel-import

Confirm sheet selection, column mapping, data types and duplicate policy before import. Validate rows and report actionable errors. For xlsx/Supabase projects, specify upsert conflict keys and transaction/error behavior; do not assume the first sheet or overwrite existing rows implicitly.

This public example is independent of private skill content. Legacy conversion preserves the existing reviewed skill verbatim.
