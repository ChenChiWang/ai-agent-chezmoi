# review

Inspect the actual diff and surrounding behavior. Prioritize concrete regressions, missing error handling and exposed credentials. Apply React, Zustand, Supabase and D3 checks only when the project uses them. Never expose secret values while reporting findings.

This public example is independent of private skill content. Legacy conversion preserves the existing reviewed skill verbatim.
